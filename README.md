# Flock Eyes

Counts dairy cows and recognises each one again, on the phone.

- **Android app** (`android/`): being built. It will be published as an APK under Releases.
- **Web version** (`web/index.html`): the first, simpler version, for a browser.
- **Models** (`models/`): the cow finder (YOLOX) and the recognition model (MegaDescriptor), with their licences.
- **Tools** (`tools/`): prepare and measure the recognition model; run by the *Models* workflow.
